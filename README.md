# Ye Naing Portfolio

Expo-based React Native portfolio app generated from the provided CV. The app is designed to run on Android, iOS, and web.

## What is included

- Modern one-page portfolio UI
- Resume-driven content for profile, skills, experience, and projects
- `Download CV` action
  - Android/iOS: generates a polished PDF and opens the native share/save flow
  - Web: downloads a PDF file directly
- A standalone modern CV file at [docs/YeNaing_Modern_CV.html](/home/yenai/Desktop/pofolio/docs/YeNaing_Modern_CV.html)

## Run locally

```bash
npm install
npm run start
```

Then open the app with Expo Go, an emulator, or the web target.
